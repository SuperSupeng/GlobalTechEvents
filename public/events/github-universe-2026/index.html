FAQ

When was GitHub Universe 2026?

GitHub Universe 2026 was 28-29 October 2026 at Fort Mason Center in San Francisco. The official agenda also lists invitation-only programming on 27 October and a separate Day of Learning on 30 October at GitHub headquarters. That extra day needed its own ticket and was listed as sold out.

Where was GitHub Universe 2026?

The main meeting was at Fort Mason Center, 2 Marina Boulevard, San Francisco. Attendance was in person and virtual. The GitHub blog and githubuniverse.com both name Fort Mason Center for 28-29 October 2026.

How much was a GitHub Universe 2026 pass?

The official Universe listing at githubuniverse.com lists an in-person pass at $1,399 and a virtual pass as free. Groups of four or more were listed at $1,119 per pass. The pricing page now marks in-person sold out. The 2026 meeting has already run.
